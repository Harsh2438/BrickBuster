# BrickBuster
BrickBuster is a classic Brick Breaker / Breakout-style arcade game developed using Java Swing. It recreates the retro paddle–ball–brick gameplay with smooth controls, realistic ball physics, collision detection, and dynamic brick layouts

# Download Link:  https://github.com/Harsh2438/BrickBuster/releases/download/v1.0/BrickBuster.jar

# How to Run
   1. Make sure Java is installed (`java -version`)
   2. Run: java -jar BrickBuster.jar

✨ Features

🧱 Multiple rows & columns of bricks

🎯 Accurate collision detection (ball–brick, ball–paddle, wall boundaries)

⚡ Smooth animations using Timer-based game loop

🕹️ Keyboard-controlled paddle movement

❤️ Life system + scoring

🎨 Custom colors, rendering, and UI elements

🔀 Randomized brick colors for better visuals


Tech Stack:
Java
Swing (JFrame, JPanel, Graphics2D)
AWT (KeyListener, Timer, Color, Font)
Object-Oriented Architecture
